{% extends "base.html" %} {% block title %}Approvals · Avanyam LMS{% endblock %} {% comment %} The approval screen. This is the whole point of the page: a trainer opens it to make a decision, so the default view is the pending queue and nothing else. Two deliberate choices: * Status tabs instead of one long list. "Pending" is what needs action; approved and declined are history you occasionally want to check, not scroll past. The counts come from the view over the same rows that are rendered, so a tab can never claim "3 pending" above a list of five. * The note field sits inside the decision form rather than in a modal. A dialog would have to trap keyboard users to be dismissable, and the thing being confirmed -- declining someone's registration, permanently blocking that email -- deserves to be visible in the page, not behind a click. {% endcomment %} {% block content %}
