{% extends "base.html" %} {% block title %}People and roles · Avanyam LMS{% endblock %} {% comment %} Admin-only role management (D49). This is the demote button: a trainer who should not be delivering courses any more goes back to trainee here, in one action, without a new application. It is a separate page from the approval queue on purpose. The queue is about applications nobody has decided yet; this is about people who already have access. Putting them on one screen makes a list do two unrelated jobs, and the filter that would fix that is the per-trainer filter we just deleted. `admin` is deliberately not an option anywhere on this page. Admins are minted with `manage.py createadmin`, so this screen cannot become a quieter second route to admin. The policy enforces it; the absent option is only so the interface does not offer a button that is guaranteed to fail. {% endcomment %} {% block content %}
